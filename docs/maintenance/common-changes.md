# Where do I change this?

Application paths in this table are relative to `src/`; `supabase/` paths are repository-relative.
Read the feature guide before changing its business rules.

| Task                        | Start here                                                               | Also check / tests                                                                           | Warning                                                                 |
| --------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Product information/prices  | Authorized `/admin/products`                                             | `server-catalog.ts`, local `007_catalog`                                                     | Do not overwrite operational values with seeds                          |
| Catalog UI                  | `components/creations/product-configurator.tsx`                          | `commerce.test.ts`, [catalog](../features/catalog.md)                                        | Browser totals remain estimates                                         |
| Checkout form               | `components/checkout/checkout-content.tsx`                               | `app/checkout/actions.ts`, [checkout](../features/checkout.md)                               | Preserve retry UUID and selected cart identity                          |
| Checkout receipt            | `components/checkout/checkout-order-summary.tsx`                         | Shared `orders/order-line-items.tsx`, summary tests                                          | Same box/add-on/quantity meaning as order history                       |
| Authoritative pricing       | `lib/server-checkout.ts`, `lib/commerce.ts`                              | `server-commerce.ts`, current writer, `commerce.test.ts`, local `002_payments`/`011_loyalty` | Reload live prices; never trust browser totals                          |
| Stock reservation/release   | Current `create_pending_order`, expiry/cancellation RPCs                 | [SQL map](../architecture/database.md), local `008_inventory`/`002_payments`/`003_refunds`   | Preserve SQL locks and provider-first release                           |
| Pickup behavior             | `lib/server-pickup.ts`, `lib/server-commerce.ts`, `lib/pickup.ts`        | `pickup-manager.tsx`, current writer, local `009_pickup`                                     | UI availability alone is not authoritative                              |
| Order labels or history     | `lib/order-status.ts`, `lib/server-orders.ts`, `components/orders/`      | `order-status.test.ts`, `orders-list.test.tsx`                                               | Payment and fulfillment are separate                                    |
| Allowed order transitions   | `transition_order_status` and payment/cancellation RPCs                  | Admin actions, local `004_admin_orders`/`002_payments`/`003_refunds`                         | Do not add an unrestricted status update                                |
| Payment verification        | `app/api/webhooks/paymongo/route.ts`, `lib/paymongo-webhook.ts`          | `paymongo-contract.ts`, `paymongo-mode.ts`, SQL paid RPC and tests                           | Keep raw-body signature, mode, exact amount/reference and dedup checks  |
| Notification triggers/copy  | SQL enqueue triggers / `lib/notification-email.ts`                       | `server-notifications.ts`, `012_notifications`, email tests                                  | Email failure must not alter order/payment; new event requires approval |
| Admin functionality         | `app/admin/<area>/page.tsx`, `actions.ts`, named manager editor          | `server-<feature>.ts`, RPC, matching pgTAP test                                              | Guard every mutation and preserve audit records                         |
| Google login or permissions | `lib/auth.ts`, `app/auth/`, `lib/auth-redirect.ts`                       | `proxy.ts`, RLS, redirect tests, `001_auth_rls`                                              | No browser-only role checks or shared private caches                    |
| Journal/reviews             | `server-journal.ts`, `server-reviews.ts`, corresponding editors          | `005_reviews`, `006_journal`                                                                 | Owner/completed-order review rules and moderation remain                |
| Add/change database field   | New `supabase/migrations/` file                                          | RLS/grants, reads/RPCs/snapshots, generated types, local suite                               | Never edit applied history or generated types manually                  |
| Shared forms/modal close    | `hooks/use-form-gate.ts`, `hooks/use-editor-dialog.ts`, `components/ui/` | `editor-contracts.test.tsx`, [design](../ui/design.md)                                       | Keep named native form plumbing, dirty/pending handling and focus       |
| Loading artwork/layout      | `components/layout/app-loading-skeleton.tsx`, fixture                    | `app/loading.tsx`, generated `src/bones/`, [design](../ui/design.md)                         | Do not capture private pages or delay display artificially              |

For a new field, trace every reader/writer before migration: does it belong in current catalog,
immutable order snapshots, an audit row, or a client-only DTO? A field visible in Admin may also
affect checkout, receipt history, email, and database validation. See [boundaries](../architecture/client-server-boundaries.md).
